About This Project

The Lich's Tower is an interactive fantasy adventure developed as a final project for the WDD 131: Dynamic Web Fundamentals course at BYU-Idaho.

The story and game concept were adapted from an original text-based adventure written in Python by Vitor Soares Fernandes.

Typography

This website uses the Cinzel and Lora typefaces, provided through Google Fonts.

  • Cinzel — Google Fonts
  • Lora — Google Fonts

Artwork

The tower illustration featured on the homepage was generated with OpenAI's image generation tools for this project.

Development

The website was developed using HTML, CSS, and JavaScript. Game progress is stored locally in the browser using the Web Storage API.

AI assistance was used during development for code explanations, debugging, and planning.
